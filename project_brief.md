# My agent: travel-concierge
One-liner: A conversational agent that helps travelers plan personalized trips with a catalog of destinations and activities.

Tool coverage:
- Memory: User travel preferences, budget constraints, dietary needs, and past trip history
- Tools: Look up destination details, weather forecasts, and attraction recommendations
- Catalog/UI: Curated collection of destinations, hotels, and daily itinerary cards
- Image gen: Generates custom destination previews and landmark artwork
- Sandbox: Calculates trip budgets, currency conversions, and itinerary cost breakdowns

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Live external maps API, video generation with Omni, Cloud Trace observability
