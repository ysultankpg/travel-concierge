Travel Concierge
an AI that actually plans the trip

A conversational travel agent built on the Google Agent Development Kit. It recommends destinations against a real budget, builds day-by-day itineraries, checks live weather and exchange rates, remembers dietary restrictions between sessions, and renders results as rich A2UI cards.

View source Run it locally

What it does

🗺 Grounded recommendations

Filters a curated destination catalog by budget, season, and interest — and says plainly when the catalog has no match rather than inventing one.

🌤 Live conditions

Real current weather and a 7-day forecast for anywhere on earth, plus correct local time and UTC offset for any city.

💱 Exact budget maths

Live ECB reference rates with explicit amount conversion, so trip costs are computed rather than estimated in the model's head.

🧠 Persistent memory

Remembers travel preferences, budget, and allergies across conversations via Vertex AI Memory Bank, and checks them before recommending food.

🎨 Rich A2UI cards

Structured itineraries, cost breakdowns, and weather strips stream into the chat as rendered cards instead of walls of prose.

🖼 Generated previews

Photoreal destination imagery on demand — and an honest "unavailable" rather than a broken link when generation fails.
